# Minecraft Bedrock Behavior Pack: SMP Starter Kit

SMP Starter Kit is a Minecraft Bedrock behavior pack and Script API plugin that gives each new player a one-time starter SMP kit when they first join a world.

## Install

1. Use the `SmpStarterKit_BP` folder as the behavior pack source.
2. To create an importable pack, compress the contents of `SmpStarterKit_BP` into a ZIP archive.
3. Rename the archive to `SmpStarterKit.mcpack`.
4. Open the `.mcpack` file with Minecraft Bedrock Edition to import it.
5. Edit the world where you want the kit to be available.
6. Open the world’s Behavior Packs settings and activate SMP Starter Kit.
7. Start or reload the world.

## Use

1. Join the world with the behavior pack active.
2. On your first spawn, you receive one starter kit automatically.
3. The kit contains:
   - 1 stone sword
   - 1 stone pickaxe
   - 1 stone axe
   - 1 stone shovel
   - 16 oak logs
   - 16 bread
   - 32 torches
4. A player tag records that the kit was received, so reconnecting does not grant the kit again.
5. The player receives a welcome message after the kit is added.
